## Сервис купли-продажи "Buyalliti" работающий асинхронно на FastAPI

### Для запуска потребуется:

1. Создать и заполнить .env-файл <br>
(Некоторые значения уже предустановлены в .env-examole и для запуска в контейнере менять их не нужно)

2. Создать и активировать виртуальное окружение
    ```bash
    python3 -m .venv venv && sourse .venv/bin/activate
    ```

3. Установить зависимости
   ```bash
   pip install -r requirements.txt
   ```
   
4. Создать и запустить контейнеры 
    ```bash
    docker-compose up -d     
    ```
   
5. Дождаться запуска контейнеров и старта вэб-сервера

### О проекте
Вэб-сервер будет доступен по адресу http://127.0.0.1:8080 <br>
Предусмотрена аутентификация и авторизация по стандарту JWT <br>
После создания пользователя, получить токен можно по маршруту /login предоставив имя и пароль<br>
Время действия токена равно 48 часам, после этого токен не действителен и следует создать новый 

Документацию по API с доступными ресурсами их методами и примерами можно найти по адресу http://127.0.0.1:8080/docs 
при запущенном сервисе <br>
Важное уточнение: испытать методы API требующие аутентификации через документацию от FastAPI
не получиться - для этого отсылайте запросы другими удобными вам способами
